# ContextMesh

团队共享上下文池，让成员在各自的 AI 助手中使用同一份有来源、适用范围和版本的项目决定。

例如，企业试点改用邮箱登录，公众注册继续使用短信。产品经理确认变更后，工程师在另一款助手中生成验收用例时，应当能区分两类人群，并引用各自适用的依据。

## 项目状态

项目处于设计与验证阶段。下载并在浏览器中打开[图解产品提案](docs/proposal.html)，可查看交互示例、技术设计、竞品对照和试点标准。

## 首个验证目标

1. 从一个客户端发布经过确认的决定，保存来源、生效时间和适用范围。
2. 用另一个客户端的项目成员身份查询，返回有权访问的有效版本。
3. 对一条局部变更分别查询企业试点与公众注册，核对返回的规则与出处。
